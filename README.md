# 弐寺課題曲通知Bot

## 概要
beatmania IIDXの課題曲情報を管理し、
LINE公式アカウントを通じて通知するBotを開発する。

## 目的
- 課題曲情報の通知
- LINEを使った課題曲の確認
- 将来的なプレイ成績との連携

## 使用技術（予定）
- Python
- LINE Messaging API
- GitHub
- GitHub Actions
